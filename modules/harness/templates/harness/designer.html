Signal Connection Rules

Define which signal types are allowed to connect to each other, e.g. PWR ↔ PWR, GND ↔ GND, RX ↔ TX. A signal name with no rule listed here is unrestricted. These rules apply everywhere a pin can be picked for a new wire.

Order parts

The harness needs a plug at each connector it goes to. Pick the part for each plug (it's remembered in the harness); without one, the device connector's own part is suggested, and its mating part may differ. This makes a draft order in Orders: add the supplier and budget there before placing it.
